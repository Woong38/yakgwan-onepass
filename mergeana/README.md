# 머지않아(Merge-Ana) — 보고서 자동 취합기

부서별로 나뉘어 작성된 문서를 원문(질문지) 순서대로 자동 취합하고 서식을 통일하는 단일 HTML 도구.

페이지: https://woong38.github.io/yakgwan-onepass/mergeana/

## 해결하는 문제

감사 자료요구서처럼 **하나의 질문지를 여러 부서가 나눠 작성**한 뒤 다시 합쳐야 하는 업무에서,
취합 담당자가 순서를 맞추고 서식을 손보는 수작업을 줄인다.

| 구분 | 수작업 | 도구 사용 |
|---|---|---|
| 순서 정렬 | 질문지와 대조하며 수동 배치 | 원문 항목 순서대로 자동 배치 |
| 서식 통일 | 부서별 글꼴·들여쓰기 수동 정리 | 일괄 통일 |
| 누락 확인 | 눈으로 대조 | 미작성 항목 표시 |

## 사용 순서

1. **원문(질문지)** 파일을 올린다 — 항목 순서의 기준이 된다
2. **부서별 작성분**을 모두 올린다 (여러 개 동시 가능)
3. 취합본을 확인하고 내려받는다

## 데이터 취급

- 올린 문서는 **브라우저 안에서만 처리**되며 서버로 전송되지 않는다.
- 외부 스크립트·폰트·API를 사용하지 않는 자체완결 파일이다.
- 화면의 예시 표기는 전부 가상이다.
