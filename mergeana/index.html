원문(질문지) 올리기

항목 순서의 기준이 되는 파일입니다. 지원 형식: .hwpx / .docx / .hwp / .txt. 업로드하면 번호 체계를 읽어 항목 목차를 만듭니다.

여기에 원문 파일을 끌어다 놓기 또는 클릭해서 선택 · 한 개만 올립니다

항목 목차

배정 단위로 쓸 항목만 체크하세요. 제목은 직접 고칠 수 있습니다(원문 파일은 바뀌지 않습니다).

부서별 작성분 올리기

부서별로 작성한 파일을 여러 개 한 번에 올릴 수 있습니다. 파일 하나에 항목이 여러 개 있어도 번호 체계를 따라 자동으로 쪼갭니다.

부서별 작성분을 끌어다 놓기 .hwpx / .docx / .hwp / .txt · 여러 개 동시 가능

붙여넣기로 추가

한글에서 본문을 복사해 붙여넣으면 텍스트 작성분으로 등록됩니다. 표는 셀 구분이 탭으로 유지됩니다.

취합 현황 — 어느 파일이 어느 항목으로 갔는지

왼쪽이 원문 항목, 오른쪽이 배정된 작성분입니다. 색 띠가 파일을 뜻합니다. 배정이 틀리면 오른쪽에서 직접 바꾸세요.

배정되지 않은 작성분

항목과 짝을 못 찾은 덩어리입니다. 항목을 직접 골라 붙이거나, 빼고 진행하세요.

서식 규칙

글자·번호·숫자 표기만 손댑니다. 본문 문장은 그대로 둡니다. 내용에 손이 닿는 항목(숫자·날짜 표기)은 기본 꺼짐이고, 켜면 바꾼 내역이 전부 기록됩니다.

한글에서 열려면 한글 문서(.hwpx), 워드까지 함께 쓰려면 문서(.doc)를 받으세요. 미리보기는 화면 색을 따르고, 저장되는 문서는 흰 종이에 검은 글씨입니다.

표기 변경 내역

숫자·날짜 표기 통일로 글자가 바뀐 곳입니다. 감사 대응 시 근거로 쓰세요.
