# Market Risk-Q — 시장리스크 표준방법 계산 엔진 (FRTB-SA)

바젤Ⅲ 최종안 시장리스크 표준방법(FRTB-SA) 자기자본 필요액을 산출하고, 근거 규정을 함께 조회하는 단일 HTML 도구.

페이지: https://woong38.github.io/yakgwan-onepass/marketrisk-q/

## 산출 범위

- **민감도기준법(SBM)** — 델타·베가·커버쳐, 7개 리스크군 전체
  - GIRR, CSR(비유동화), CSR(유동화 CTP), CSR(유동화 非CTP), 주식, 외환, 일반상품
- **채무불이행리스크(DRC)**
- **잔여리스크 추가액(RRAO)**
- 상관계수 시나리오 3종(high·medium·low) 비교 후 최대값 자동 선택

## 주요 기능

| 기능 | 내용 |
|---|---|
| 포지션 업로드 | CSV 템플릿(24개 컬럼) 다운로드 → 실제 포지션 업로드 |
| 샘플 데이터 | 가상 트레이딩북 포지션으로 즉시 시연 |
| 근거 규정 표기 | 산출값마다 조문·산식을 배지로 확인 |
| 규정 Q&A 검색 | 별표3-2 조문 128건·각주 63건 전문 검색 |

## 데이터 취급

- 업로드한 포지션은 **브라우저 안에서만 처리**되며 서버로 전송되지 않는다.
- 외부 스크립트·폰트·API를 사용하지 않는 자체완결 파일이다.
- 수록 예시는 전부 가상 포지션이다.

## 근거

- 은행업감독업무시행세칙 [별표 3의2] 제6장
- 바젤Ⅲ 최종안 기준 시장리스크 규제체계 기준서(금융감독원, 2021.1.15.)
