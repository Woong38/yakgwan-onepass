# 약관 원패스 체험판

약관 변경 시 신구조문 대비표, 금감원 보고(신고) 공문·보고서, 변경안내문, 시행문을 자동 작성하는 도구의 외부 테스트용 페이지.

- 모든 예시 데이터는 가상이다.
- 입력 내용은 브라우저에만 저장되고 서버로 전송되지 않는다.

페이지: https://woong38.github.io/yakgwan-onepass/
