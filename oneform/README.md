# 사업계획 원폼(One Form) 체험판

사업계획 양식 배포 → 팀 작성 → 부서 기획팀 합치기 → 취합부서 최종 취합을 파일 하나로 처리하는 도구의 외부 테스트용 페이지.

- 페이지: https://woong38.github.io/yakgwan-onepass/oneform/
- 예시 양식(가상): [워드](sample/sample_template.docx) · [파워포인트](sample/sample_template.pptx)
- 모든 처리는 브라우저 안에서 끝나며, 입력 내용은 서버로 전송되지 않는다.
- 예시 데이터는 모두 가상이다. 실제 사업계획 내용은 입력하지 않는다.
